# ButtonCraft ⚡

Curated collection of 20+ aesthetic, animated, and unique interactive button components designed for modern web applications and design templates.

Includes instant 1-click code copying for **CSS**, **HTML**, and **React / JSX**.

🔗 **Repository**: [https://github.com/irbahtaqiy/button-craft](https://github.com/irbahtaqiy/button-craft)

---

## ✨ Features

- **20 Unique Button Styles**:
  - **Minimal & SaaS**: Minimal Pill Fill, Neumorphic Concave, Particle Sweep Arrow, Sunset Gradient Flush.
  - **Glow & Aura**: Shimmer Border Aura, Aurora Borealis Glow, Tron Wireframe Glow, Spotlight Cursor Tracker, Electric Neon Beam.
  - **Cyberpunk & Glitch**: Cyberpunk Breach Slice, CLI Terminal Prompt.
  - **3D & Tactile**: 3D Extruded Gaming Switch, Neo Brutalist Pop, Hazard Stripe Caution.
  - **Glassmorphism**: Liquid Mercury, Frosted Prism Glass, Holo Foil Prism.
  - **Retro & Playful**: 8-Bit Arcade Quest, Squishy Jelly Pop, Sonar Radar Ping.
- **Interactive Playground**: Real-time hover, click physics, and mouse-tracking spotlights.
- **Instant Code Exporter**: One click to copy pure CSS, HTML structure, or a modular React component.
- **Ultra-fast Search & Filter**: Filter by aesthetic category (*Minimal, Glow, Cyberpunk, 3D, Brutalist, Glass, Retro, Playful*) or search by keywords.
- **Zero Heavy Runtime**: Pure CSS animations and vanilla TypeScript for blazing performance.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/irbahtaqiy/button-craft.git
cd button-craft
```

### 2. Install dependencies & run development server
```bash
npm install
npm run dev
```

### 3. Build for production
```bash
npm run build
```

The production output will be generated inside the `dist/` directory.
